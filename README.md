# Site du Chalet des Quatre Pierres

Site internet du Chalet des Quatre Pierres, dit « Le Pointu », chalet de 14 personnes au Grand Valtin (Ban-sur-Meurthe-Clefcy, Vosges).

Domaine de production : chalet-4-pierres-location.fr

## Comment ce site est géré
- Le site est entièrement construit et mis à jour par Claude, à la demande de Manon.
- La source unique d'information (tarifs, équipements, règles) est la **fiche de référence du chalet**, dans le projet Claude « Chalet ». Toute modification de contenu commence par cette fiche.
- Le site est statique : pas de PHP, pas de base de données.
- Hébergement : Netlify. Le domaine reste chez IONOS.
